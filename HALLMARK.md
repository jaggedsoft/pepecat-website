# Hallmark stamp

**PEPECAT Culture Archive — stamped 2026-08-11**

Direction: midnight collectible, mischievous, precise, art-led.

## Signature decisions

- A full-width editorial masthead and oversized mascot stage establish culture before conversion.
- The archive uses an asymmetric, cut-corner shuffle wall with session-stable random selections and an accessible lightbox.
- Pc03 is the sole emoji-style hero focal point; the former expression reel and decorative avatar cameos were removed so richer community illustrations can lead the archive.
- The token receipt presents evidence as a compact ledger with the full mint, copy feedback, and verified destinations.
- Coral is the only interface accent; neon green stays primarily inside the artwork.
- Motion is limited to the one-time hero settle and archive reorder crossfade, with both removed under reduced-motion preferences.

## Slop-test audit

- [x] No glassmorphism, gradient text, fake app chrome, floating dashboard cards, or generic feature grid.
- [x] No excessive pill controls, ornamental badges, random icon soup, or decorative statistics.
- [x] No roadmap filler, unsupported achievements, safety guarantees, or speculative token claims.
- [x] One H1, ordered section headings, visible focus states, 44-pixel touch targets, and meaningful media labels.
- [x] Real project artwork drives every major composition; no stock image substitution.
- [x] Desktop and mobile layouts were inspected against five section-specific concept renders.
- [x] Runtime media is local, lazy-loaded below the hero, and dimensioned to prevent layout shift.
- [x] Reduced-motion, keyboard lightbox behavior, controlled video playback, and clipboard feedback are covered by automated tests.
- [x] Production Lighthouse: Performance 95, Accessibility 100, Best Practices 100, SEO 100.
